# 文脈に沿った知識化（T-3000）

Owner指示、詳細はOwner事前承認（上位AGENTS.md §2.1）。正本は上位spec §3.3.13 B、ADR-0043、testing §28。仕様を先に記録して実装した。コード案は子エージェントに委譲したが、その環境にファイル／execツールがなく、本文で受け取って親が共通llm APIに合わせ適用した。

既存の保存候補（言い回し・知識としてのObsidian依頼・保存命令）の開始前に文脈を確認する。未実施のインタビューや質問・調査、否定・後での依頼は保存を開始せず、原文と会話履歴を通常の会話へ渡す。単純な現在の保存命令は追加の推論なし。その他の複合依頼は既存Ollamaへ直近最大12発言（各600字）を渡して判断し、8秒の上限・不正出力・失敗は保存開始にしない。この判定は既存の保存候補を拒否するためだけで、書き込み権限を追加しない。

会話共通プロンプトでも、先にインタビューして答えに応じて質問すること、未実施の作業を完了扱いしないこと、毎回の知識化の勧めを避けることを明記した。既存の確認・保存待ち・会話終了時の処理・明示ノート編集は変えない。予約や自動保存の機構は追加しない。

ローカル実モデルの読み取り評価（合成した入力のみ、本番保存・ツール・外部APIなし）:

| 入力 | 即時知識化 | 所要時間 |
|---|---|---|
| インタビューして、その内容をナレッジ化して | しない（明確な先行作業） | 0.00秒 |
| ナレッジ化してと言ったら何が起こるの？ | しない | 3.06秒 |
| インタビューをお願いします。その結果をナレッジ化してほしい | しない | 1.95秒 |
| インタビューは終わりました。この内容も入れてナレッジ化してほしい（終了までの履歴あり） | する | 2.17秒 |

さらに共通プロンプトで「ピアノ教室の方針について私にインタビューして、その内容をナレッジ化して。まず質問して。」を与え、対象年齢層／大切にする教育方針を聞く応答（7.07秒）を確認。「子どもが自分で音楽を楽しめるようになることを大切にしています」と答えると、具体的な指導法を聞く次の質問（2.03秒）になり、保存の繰り返し案内はなかった。これはローカルモデルによる合成評価で、Windowsの実音声・Claude/Codexの新規会話の実測とは区別する。

検証は最新main（画面配置の#97）統合後の全pytest 1,711件成功（147.01秒、既存のGoogle試験と予備索引の警告4件）、完了済み表現の調整後は関連87件を再実行して成功（1.89秒）。統制スクリプト37件、追加行の秘密情報0件。

テストは新しい文脈判定の単体試験と、インタビュー→回答→明示的知識化の実行経路を含む。既存の保存・Vault連携テストでは文脈分類だけを偽物にし、既存の保存／確認／検索のアサーションは維持した。判定自身の誤出力・失敗・履歴は独立した新規テストで検証する。
